Creating Word Documents With Branding Kits

Learn how to write effective prompts that help Copilot create professional Word documents whilst following Interact branding standards.

Why Prompt Structure Matters

Copilot performs best when you provide clear instructions about the branding template, audience, content and expected outcome.

The more specific your prompt is, the more likely Copilot will generate content that requires minimal editing.

Tell Copilot Which Template To Use

Refer to the approved Interact branding template you want to use.

Explain The Purpose

Clearly describe what the document should achieve.

Define The Length

Tell Copilot how much detail is required and any page limits.

Example Prompt Structure

A strong prompt typically contains four key areas:

01

Template

Identify the approved branding template.

02

Content

Explain what the document should cover.

03

Rules

Include any branding or formatting requirements.

04

Outcome

Define the expected result.

Example Branding Kit Prompt

Use the Interact Internal Branding Kit using the Word Basic Template from the Brand Templates Library. Do not alter the template structure, branding, colours, fonts, logos, spacing, headers or footers. Create a Word document explaining how to use Branding Kits. Document length: no longer than 2 pages. Branding Rules: • Do not use non-approved fonts. • Do not alter logo proportions or colours. • Do not use colours outside the Interact palette. • Keep layouts simple and uncluttered. • Ensure accessibility and readability are maintained.

Branding Rules To Include

Approved Fonts

Ensure only approved Interact typography is used.

Approved Colours

Stay within the approved colour palette.

Accessibility

Keep content readable and easy to navigate.

Common Mistakes

Vague Requests

Avoid asking for "a document" without explaining its purpose.

Missing Audience

Tell Copilot who the document is intended for.

No Length Guidance

Specify expected page count or level of detail.

Missing Branding Instructions

Include branding expectations within the prompt.
