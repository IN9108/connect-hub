Using Branding Kits Without A Premium Copilot Licence

You don't need a Premium Copilot licence to benefit from Branding Kits. Learn how to create branded content using Copilot alongside Microsoft Word and other Microsoft 365 applications.

No Premium Licence? No Problem.

Whilst Premium users can access branding templates directly through Create, users without a Premium licence can still use Copilot to help generate branded content.

The key difference is that you'll typically start within an existing Microsoft application such as Word and use Copilot to assist with content creation.

Create New Documents

Use Copilot prompts to generate content and then apply approved branding standards.

Use Copilot In Word

Work directly inside Word using Copilot to help draft, improve and structure content.

Two Ways To Work

OPTION 1

Generate Content

Ask Copilot to create a document using prompts and then refine the output.

OPTION 2

Work In Word

Use Copilot directly inside Word to draft, rewrite and improve existing content.

Understanding The Limitation

Word cannot currently apply a complete Branding Kit template in the same way as the Premium Create experience.

Instead, Word can currently apply key branding features such as fonts and colours. Full Branding Kit support is expected in the future.

Best Practice Guidance

Use Approved Templates

Start from approved company templates wherever possible.

Review Branding

Check that fonts, colours and layouts align with company standards before sharing.

Refine The Output

Treat Copilot as a draft creator and always perform a final review.

Key Takeaway

A Premium Copilot licence makes access to Branding Kits easier, but users without Premium licensing can still create professional, on-brand content by combining Copilot with approved company templates and Microsoft 365 applications.
