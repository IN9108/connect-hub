What Is A Prompt?

Before learning prompt writing, it's important to understand what a prompt actually is. The good news is you've probably been using prompts your entire life without realising it.

What Is A Prompt?

A prompt is simply an instruction, request or question that you give to an AI tool such as Microsoft Copilot.

Every time you ask Copilot to summarise information, explain a topic, draft content or generate ideas, you are using a prompt.

Prompt writing is simply learning how to communicate your request more clearly so Copilot understands exactly what you need.

You Already Use Prompts Every Day

Asking Questions

"What meetings do I have today?"

Requesting Help

"Summarise this document for me."

Creating Content

"Write an email explaining a customer order delay."

What Can Prompts Help With?

Learning

Ask Copilot to explain topics, policies or business processes in simple language.

Research

Summarise information, identify key points and discover useful insights.

Drafting

Create emails, documents, presentations and reports faster.

Ideas

Generate suggestions, recommendations and alternative approaches.

Analysis

Review information, identify trends and highlight important findings.

Productivity

Save time by reducing repetitive manual work and information gathering.

Examples Of Prompts

Prompts can be as simple as asking a question or requesting help with a task.

Learning Prompt

Explain broadband speeds in simple terms.

Drafting Prompt

Write a professional meeting summary.

Idea Generation Prompt

Suggest ways to improve customer communication.

What Makes A Good Prompt?

Be Clear

Tell Copilot exactly what you would like it to do.

Add Context

Provide relevant information that helps Copilot understand the task.

Describe The Outcome

Explain what you want the final response to look like.

Copilot In Action

Simple Prompt

Summarise this meeting.

Copilot will generate a summary, but it may not include everything you need.

Improved Prompt

Summarise this meeting for a Team Leader. Include key decisions, follow-up actions and outstanding questions using bullet points.

Both prompts work, but the second provides more guidance and usually produces a more useful result.

Think Of It Like Giving Instructions

Copilot Can Only Work With The Information You Provide

Imagine asking a new colleague to complete a task. The more clearly you explain what you need, the better the outcome is likely to be. The same principle applies when working with Copilot.
