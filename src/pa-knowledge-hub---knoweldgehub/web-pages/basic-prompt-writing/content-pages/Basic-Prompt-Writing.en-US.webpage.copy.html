Basic Prompt Writing

Think of a prompt as giving instructions to a new employee who knows nothing about the task. The clearer your instructions, the better Copilot can help you.

What Is A Prompt?

A prompt is the instruction, request or question you give to Copilot.

Prompt writing does not require technical knowledge or coding skills. It's simply about explaining what you need, providing enough context and being clear about the outcome you are looking for.

Why Good Prompts Matter

Better Results

Clear instructions help Copilot generate more relevant and useful responses.

Save Time

Good prompts reduce the need to repeatedly refine your requests.

Improved Accuracy

Providing context helps Copilot better understand what you are trying to achieve.

Common Mistakes

Too Vague

Requests such as "help me with this" or "write something" provide very little direction.

Missing Context

Without background information, Copilot may not understand the purpose of the task or who the output is for.

No Output Requirements

If you don't specify the format, length or tone, the response may not meet your expectations.

A Simple Prompt Formula

Basic prompt writing follows a simple structure. The more information you provide in each area, the more helpful Copilot can be.

Action

Tell Copilot what you want it to do.

Example: Create a PowerPoint presentation.

Subject

Explain what the task is about.

Example: Week-on-week performance.

Context

Provide background information.

Example: Use the attached files to analyse performance.

Audience

Explain who the output is intended for.

Example: Senior Leadership Team.

Tone

Describe how the content should sound.

Example: Professional and concise.

Output

Explain what the final response should look like.

Example: Five slides with speaker notes.

Poor Prompt Vs Better Prompt

Poor Prompt

Create a presentation.

This prompt provides very little information about the objective, audience or expected outcome.

Better Prompt

Create a PowerPoint presentation reviewing week-on-week performance. Analyse the attached files, highlight key trends and notable changes, and prepare the presentation for the Senior Leadership Team. Keep the tone professional and concise. Create five slides with speaker notes.

This prompt clearly explains the task, audience, context and desired output.
