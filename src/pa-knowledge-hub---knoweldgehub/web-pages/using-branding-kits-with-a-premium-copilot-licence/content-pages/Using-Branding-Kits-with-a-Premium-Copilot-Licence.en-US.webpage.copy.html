Using Branding Kits With A Premium Copilot Licence

Learn how Premium Copilot users can access approved Interact branding templates directly through the Create experience and start generating branded content faster.

What Changes With A Premium Licence?

The biggest difference is access to the Create experience within Microsoft Copilot.

Create allows you to select approved branding templates before generating content, helping ensure presentations, documents and other deliverables are aligned with Interact branding from the beginning.

Access Branding Kits Directly From Create

Branding kit templates can be accessed directly from the Create experience. Brand templates are available through the More menu, allowing you to start from an approved template rather than a blank file.

Locate and open the Create experience within Copilot.

Benefits Of Using Create

Faster Start

Begin with approved branding instead of manually formatting documents from scratch.

Improved Consistency

Ensure content created across teams follows the same visual standards.

Less Rework

Reduce time spent fixing layouts, colours, fonts and branding after content has already been produced.

Best Practice

Start With The Template

Whenever possible, select the branding kit template first and then generate content. This helps maintain brand compliance and reduces unnecessary formatting work later.
