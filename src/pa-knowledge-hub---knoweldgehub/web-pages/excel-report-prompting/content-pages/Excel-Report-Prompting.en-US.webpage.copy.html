Creating Excel Reports With Branding Kits

Learn how to use Branding Kits when creating spreadsheets, reports and business workbooks with Copilot.

Branding Isn't Just For Presentations

Consistent branding is equally important when creating Excel reports, dashboards and operational workbooks.

A professionally branded workbook makes information easier to understand while ensuring consistency across the organisation.

Consistent Reporting

Ensure reports follow approved Interact branding standards.

Better Readability

Standard layouts make reports easier to navigate and understand.

Professional Output

Create workbooks suitable for internal business use.

What Should Your Prompt Include?

01

Existing Template

Tell Copilot which approved Excel workbook or template should be used.

02

Report Purpose

Explain what information the workbook should contain.

03

Formatting Rules

Instruct Copilot to use approved colours, fonts and layouts.

04

Audience

Explain who will use the workbook or report.

Example Branding Kit Excel Prompt

Use the existing Generic Interact Excel Template from the Interact Internal Branding Kit as the mandatory base workbook. Do not create a new design or use generic Excel formatting. Apply all approved branding standards including: • Logos • Colours • Fonts • Headings • Tables • Layouts Ensure every worksheet is professionally formatted, visually consistent and suitable for internal business use. Create a monthly performance report showing team productivity, customer satisfaction scores and KPI trends.

Current Limitation

Excel does not currently support the full Branding Kit experience in the same way available through Premium Copilot Create templates.

At present, Excel can apply key branding elements such as fonts and colours, with expanded functionality expected in future releases.

Best Practice Guidance

Use Existing Templates

Start from approved business templates whenever possible.

Structure Data Clearly

Keep worksheets organised and easy to navigate.

Review Before Sharing

Validate calculations, formatting and branding consistency.

Common Mistakes

Creating New Formats

Avoid replacing approved workbook structures with custom designs.

Ignoring Branding Rules

Reports should still follow approved visual standards.

Unclear Requirements

Provide enough detail for Copilot to build the correct report.

Skipping Validation

Always review formulas, calculations and report outputs.
